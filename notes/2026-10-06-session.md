## Root cause
The bar drew used categories with `█` and free/buffer space with the shade glyphs `░`/`▒`. In iTerm2 the shade glyphs are drawn a few pixels shorter than the full block (confirmed with a side-by-side window capture), so the runs had different heights.

## Fix
- Every cell is `█`; kinds are told apart by colour. Free space uses the `subtle` theme colour (the engine's own colour for it is `inactive`, the same as System tools). The buffer keeps the engine's colour.
- `dimColor` together with a theme `color` had no visible effect in iTerm2, so it is not used.
- Also cleared two `claude plugin validate` warnings: added `author`, added `.catch` on the `session.compact` hook.
- Test updated: asserts one glyph across bar and legend, no shade glyphs anywhere, free run coloured `subtle`.
