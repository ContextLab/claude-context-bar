## Task
1. Fix inconsistent bar sizing in the `context-bar` mod (live copy: `~/.claude/mods/context-bar`, loaded via `CLAUDE_CODE_PLUGIN_DIRS` in `~/.claude/settings.json`).
2. Add the mod to this repo with a README (install one-liner, uninstall, screenshots).

## Root cause
The bar drew used categories with `█` and free/buffer space with the shade glyphs `░`/`▒`. In iTerm2 the shade glyphs are drawn a few pixels shorter than the full block (confirmed with a side-by-side window capture), so the runs had different heights.

## Fix
- Every cell is `█`; kinds are told apart by colour. Free space uses the `subtle` theme colour (the engine's own colour for it is `inactive`, the same as System tools). The buffer keeps the engine's colour.
- `dimColor` together with a theme `color` had no visible effect in iTerm2, so it is not used.
- Also cleared two `claude plugin validate` warnings: added `author`, added `.catch` on the `session.compact` hook.
- Test updated: asserts one glyph across bar and legend, no shade glyphs anywhere, free run coloured `subtle`.

## Observed, not fixed (engine behaviour)
On a short terminal (about 18 rows) Claude Code clips the legend's wrapped second row; at 27 rows it shows. Noted in the README.

## State
- Live mod and repo copy are identical (apart from repo-only files).
- Screenshots in `assets/` are real captures of an iTerm2 session running the fixed mod.
- Install/uninstall commands verified against the local folder with a throwaway `CLAUDE_CONFIG_DIR`.

## What was built (v0.2.0)
- Still drawn in the `PromptHint` site. Round-bordered box: header (`◆ context`, used/max, `compacts at`, percent badge), bar, legend.
- Bar: `█` for full cells, `▌` with foreground+background where two colours meet (half-cell boundaries), `▏` mark opening the buffer. No shade glyphs (the v0.1 sizing bug).
- Colours: fixed hex palette by category name (engine colour as fallback); free/buffer hex pair chosen by the `theme` row of `$.config.list()` (light vs dark).
- Animation: `frame` state atom eased toward the snapshot with `$.clock.every(40ms)` x 12 steps, ease-out cubic. `grow` from empty on session start and on show; `slide` from the drawn frame on `session.measure` / after compaction.
- Functions that take `$` must be declared at module top level (the loader refuses closures inside `register`).

Fits `floor(rows/2) - 4` (bottom slot is half the terminal, prompt's 4 rows included). `fit()` in `hooks/cells.ts` assumes 2 more rows for a status line and mode line and drops the legend, then the box. The hook is not re-asked when only the terminal's height changes.
